# Carmanline 外部 AI 导入格式

在 App 的“录入 → JSON 导入”选择公式或错题，再复制对应提示词交给其他 AI。提示词也保存在同目录的 `prompts/formula.txt` 和 `prompts/wrong.txt`。提示词由 `web/import.mjs` 的同一函数生成。

只接受内容，不接受 ID、复习日期、盒子、设置、图片或其他调度字段。每批 1～100 条，文本或文件最多 2 MB。可直接粘贴 JSON，也可保留唯一一层完整的 JSON 代码围栏；不接受前后解释或截断内容。

## 公式

顶层恰好包含 `format: "carmanline.formula.v1"` 和 `items` 数组。每项恰好包含以下字段，均为必填：

| 字段 | 要求 |
| --- | --- |
| kind | 固定为 `formula` |
| subject | 科目，1～60 字 |
| title | 名称，1～160 字 |
| latex | 完整正确公式；KaTeX 支持的 LaTeX，不含 `$`；最多 4000 字 |
| cue | 适用条件或变量说明，无则空字符串；最多 2000 字 |
| distractors | 3～8 个不同的完整错误公式字符串，不能与标答相同；每项最多 4000 字 |

## 错题

顶层恰好包含 `format: "carmanline.wrong.v1"` 和 `items` 数组。只支持单选题。每项恰好包含：

| 字段 | 要求 |
| --- | --- |
| kind | 固定为 `wrong` |
| subject | 科目，1～60 字 |
| title | 名称，1～160 字 |
| stem | 完整题干，非空；最多 12000 字 |
| options | 2～6 个不同、非空的选项字符串；每项最多 12000 字 |
| answer | 从 0 开始的整数下标；首项为 0，不能填字母或字符串 |

题干和选项中的数学用成对的单个 `$` 包裹，不使用 `$$`。JSON 字符串中的 LaTeX 反斜杠必须双写，例如 JSON 原文 `"\\frac{a}{b}"`。App 检查可渲染性，正确答案及混淆项的数学含义仍需用户核对。

## 核对与修改

JSON 外壳、类型和大小必须正确，再独立检查每个条目。通过的内容进入预览，失败的条目单独提示原因，不阻止有效内容入库；混淆项过滤后仍有至少 3 个有效项的公式可继续保留。JSON 本身若有未转义反斜杠、缺少逗号等语法错误，仍需先修正。

预览只显示文字与公式，不展示原图或截图切块。可以逐条确认、跳过或确认剩余整批；完全相同的内容会跳过。写入失败回滚本批新增内容并保留草稿。“清空”和“清除图片”只清除当前输入与对应待录入内容，不删除已入库题目。

外部 AI 的完整 JSON 请放在唯一一个 `json` 代码块中，点击代码块的复制按钮后粘贴。提示词的公式示例包含积分和分式，错题示例包含分式，均可直接通过当前 App 校验。

“对话修改”每次只修改当前条目。AI 必须返回 `{"reply":"说明","item":完整内容对象}`；不完整、类型错误或不可渲染的回复不会覆盖原草稿。手动编辑使用同样的校验。确认入库时 App 创建新 ID 与正常复习进度，外部文件不能覆盖既有记录。
